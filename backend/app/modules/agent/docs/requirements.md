# Requirements

Must-have requirements for the Autonomous Research Agent with Live Dashboard.

- [ ] Accept a natural-language research goal
- [ ] Agent plans its own steps
- [x] Agent uses 3+ tools (web search, file read/write, calculator) with real error handling
- [ ] Agent observes results and re-plans on failure
- [ ] Agent has a defined stopping condition
- [ ] Step-level logs persisted to database
- [ ] Live streaming (WebSocket/SSE) to frontend dashboard
- [ ] Structured final report as output
- [ ] Deployed publicly (Vercel + backend host + hosted DB)
- [ ] Evaluation across 5–10 goals documented
- [ ] README + demo video
